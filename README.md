# 📖 Overview

**Brindavan Conventions** is a modern, responsive frontend website developed for a convention hall and event venue. The website provides visitors with an engaging experience to explore the venue, services, facilities, gallery, pricing, and contact information.

Designed with a clean and intuitive user interface, the website helps customers easily discover the venue and inquire about bookings for weddings, receptions, corporate events, conferences, birthdays, and other celebrations.

---

# 🎯 Project Objective

The objective of this project is to create a professional online presence for a convention hall that:

- Showcases venue information
- Highlights available facilities and services
- Displays an attractive photo gallery
- Provides booking and contact information
- Delivers a seamless user experience across all devices
